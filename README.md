## ⚙ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/dipendra-pardhi/Personal-Portfolio.git
```

Move into project folder:

```bash
cd Personal-Portfolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
